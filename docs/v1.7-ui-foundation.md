# Pixel Everywhere v1.7 — visual foundation

This branch implements the **first** visual slice of the paper sketches (public interface, sheet 2).

## Included in this iteration

- Home now uses a compact logo + welcome text layout.
- A separate **Autres menus** page shows the existing application features in a two-column grid (three on wider screens).
- The bottom bar shows three entries: **Accueil / Autres menus / Compte**.
- Existing feature cards and navigation handlers remain mounted and are invoked instead of rewriting the application's business logic.
- The account tab opens the existing member/staff dialog; the existing staff-panel features are unchanged.
- The feature list is refreshed when an existing extension adds feature cards.
- Deduplication of features has a small Node.js unit test.

## Not included yet

Admin Panel redesign (sketches 1, 3–6), Discord OAuth2 and activity feed, Tamagotchi redesign, Welcome Guide redesign, and final release bump are separate milestones.

## Test

`npm test` runs existing tests and the new `test/v17-navigation.test.mjs` suite. `npm run build` verifies Vite bundling.

## Compatibility

The 1.7 layer is loaded at the end of the existing boot pipeline. If its optional import fails, the original interface stays available. No existing API routes or persisted data formats are changed in this slice.
