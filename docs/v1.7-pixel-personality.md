# Pixel Everywhere 1.7 — Pixel 2.0 : personnalité et humeurs

Cette première étape enrichit **Pixel**, la mascotte de PE, sans créer de nouvel objet à acheter ni modifier l'économie de l'application.

## Humeurs contextuelles

L'ancien calcul basé uniquement sur la moyenne des trois jauges est remplacé par des états déterministes :

- **Affamé** : faim basse et prioritaire.
- **Somnolent** : énergie très basse, ou énergie basse pendant la nuit.
- **Boudeur** : joie très basse.
- **Fatigué** : énergie basse sans être somnolent.
- **Surexcité** : joie et énergie élevées.
- **Heureux** : joie confortable.
- **Curieux** : état de repos, lorsque les autres besoins ne dominent pas.

L'affichage de l'humeur (badge, message, rythme de respiration et des yeux) utilise le même moteur dans `web/main.js` et `web/pixel-live.js` pour éviter les contradictions entre les mises à jour toutes les cinq secondes.

## Habitudes et caractère

Pixel commence **Curieux**, puis le caractère évolue avec les interactions réellement réussies :

| Habitude | Caractère affiché |
| --- | --- |
| Nourriture et achats de repas | Gourmand |
| Caresser | Câlin |
| Jouer | Joueur |
| Promener | Explorateur |
| Dormir | Rêveur |

Une habitude doit avoir eu lieu **au moins 3 fois** et dépasser la deuxième habitude d'au moins **2 interactions** pour devenir dominante. En cas d'égalité, Pixel reste Curieux. Une autre habitude peut prendre le dessus plus tard.

Les compteurs sont conservés dans la sauvegarde existante `pixel-pet` comme nouveau champ `habits`, et préservés par le module `pixel-live`. Les sauvegardes antérieures sans ce champ restent compatibles (habitudes initialisées à zéro). Les compteurs sont plafonnés pour éviter des valeurs corrompues.

## Réactions et moments calmes

- Chaque action financée (nourrir, câliner, jouer, dormir, promener, repas) sélectionne une phrase selon **l'humeur avant l'action**, la personnalité et le nombre d'interactions.
- Exemple : un Pixel affamé remercie particulièrement après un goûter ; un Pixel somnolent préfère les moments calmes.
- Sur la page Pixel, une petite pensée change environ toutes les 38 secondes **seulement quand aucune action n'est en cours** et qu'au moins 25 secondes se sont écoulées après la dernière interaction.
- Les pensées passives ne dépensent aucune pièce et ne génèrent aucun XP.
- Le mécanisme respecte les animations déjà présentes dans `pixel-live` et le réglage système de réduction des animations.

## Ce qui reste inchangé

- Les routes serveur de dépense des pièces et de contrôle des délais sont identiques.
- Les jauges actuelles, les coûts, les achats, les niveaux, l'XP et la progression existants sont conservés.
- Le stockage du compagnon est encore **local à l'appareil**. La synchronisation multi-appareils sera une étape distincte.
- Pas de nouvelle permission Android, pas d'appel à une IA externe et pas de nouveau système publicitaire.

## Tests et vérifications

Les tests dans `test/pixel-personality-v17.test.mjs` couvrent les anciennes sauvegardes, les trois types de personnalités évolutives, les égalités, la limitation des compteurs, les états d'humeur, les réactions conditionnelles et les pensées sans mutation de progression.

Avant fusion, essayer manuellement sur Android et Windows : humeur après fermeture/réouverture, alternance Pixel Live / Pixel principal, animations avec réduction des mouvements, actions refusées pour crédits/délai, et évolution d'un caractère après plusieurs actions réussies.

Cette modification est uniquement sur `feature/v1.7-ui-foundation` ; elle ne déploie pas sur Termux et ne modifie pas `main`.
